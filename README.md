# 💰 Simple Interest Calculator

A fast, accurate, and responsive **Simple Interest Calculator** built with HTML, CSS, and JavaScript.

This tool helps users calculate simple interest and the total amount quickly by entering the principal amount, interest rate, and time period.

## ✨ Features

- ⚡ Instant calculations
- 💰 Simple interest calculation
- 📊 Total amount calculation
- 🔄 Automatic result updates
- 📱 Responsive design
- 🎨 Clean and modern interface
- 🌐 Works directly in a web browser
- 🚫 No external libraries required
- 🔒 No registration required
- 🪶 Lightweight and fast
- 🌍 Cross-browser compatible

## 🧮 How It Works

Enter the following information:

- Principal amount
- Interest rate
- Time period

The calculator automatically calculates the simple interest and total amount.

The standard simple interest calculation is based on the relationship between the principal, interest rate, and time period.
